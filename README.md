# Courier Integration Platform

A full-stack platform for managing e-commerce orders and courier service integrations.

> **Work in progress.** Only the features listed below are implemented.

## Implemented

- Backend skeleton (Node.js 24, TypeScript, Express) with a `GET /health` endpoint.

## Run the backend

```bash
nvm use            # Node 24 from .nvmrc
cd backend
npm install
npm run dev        # http://localhost:3000/health
```
